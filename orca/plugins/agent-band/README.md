# Band

Orca 아래쪽 상태 표시줄에 띠를 단다. Claude 데스크톱 앱의 입력창 띠와 결재함 개수를 Orca로 옮긴 것이다.

| 항목 | 뜻 | 기본 |
|---|---|---|
| `진행 n · 대기 n` | 일하는 에이전트 수와 사용자를 기다리는 에이전트 수. 기다림 = 권한 승인(`blocked`) + 에이전트가 던진 질문(`waiting`). 기다리는 칸이 있으면 경고색이다 | 켬 |
| `오늘 갱신 세션 N 토큰` | 오늘(로컬 자정 이후) 갱신된 세션의 **누적** 토큰 합이다. 며칠 전에 시작한 세션을 오늘 이어 쓰면 그 세션의 누적이 모두 들어간다 (오늘 늘어난 양이 아니다). 최근 세션 200개까지 읽고, 더 많으면 `+`를 붙인다. 1분마다 다시 센다 | 끔 |

- **켜기·끄기:** Orca의 Settings > Plugins > Band에서 두 항목을 따로 켜고 끈다. 플러그인 전체는 Settings > Plugins에서 끄거나 `orca plugin disable local.agent-band`.
- 항목을 누르면 명령 `Band: list agents`가 목록을 보인다 (승인 대기 → 답변 대기 → 진행 순).
- 끝난 세션(`done`)은 바로 지운다. 이벤트가 끊긴 칸은 진행 중 4시간, 기다리는 칸 24시간 뒤에 지운다 (띠를 꺼도 정리한다). 상태가 바뀔 때만 이벤트가 오므로 긴 작업은 한참 조용하다.
- 에이전트 상태는 Orca의 `agent.status.changed` 이벤트다. chat UI의 세션에도 같은 상태 값이 있지만(Orca 소스에서 확인), 이 이벤트가 chat 세션에도 오는지는 설치한 뒤 눌러서 확인한다.
- 기본 끔인 이유: Orca가 자기 상태 표시줄에 5시간·주간 사용량 칩을 이미 보인다. "오늘 토큰"은 그것과 다른 값이다.
- 못 옮기는 것: 카드, 단추(`인계 ▸`), 컨텍스트 %. Orca가 플러그인에 주지 않는다 (상태 표시줄은 글자뿐이다).
- **선택 설치다.** chat UI는 Orca의 에이전트 대시보드("확인 필요" 칸)가 낫다. 이 플러그인은 터미널 창의 상태 이벤트로 세므로 chat 세션이 빠질 수 있다. 터미널 모드의 Claude는 session-board의 띠가 그대로 뜬다.
- 읽는 권한: `agent:read`, `history:read`, `settings:own`. 세션 제목과 토큰 수만 읽고, 대화 내용은 읽지 않는다.

## 시험과 설치

```sh
orca plugin test .
orca plugin validate .
orca plugin dev load .     # 코드를 도는 플러그인이라 --approve <지문>이 필요하다
```
